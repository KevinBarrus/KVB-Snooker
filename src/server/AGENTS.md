# 联机权威服务器 · 模块章程

继承[全局章程](../../AGENTS.md)；本文件只保留职责、工作约束和必读入口。

## 职责边界

- 暂停权限由已认证连接席位与当前尝试决定；复用命令去重，客户端不能冻结权威时钟。暂停检查点保存预算及剩余量，恢复撤销旧准备；请求期不阻断击球。

- 服务开发原型与内测经典联机的 Node 权威房间：每房间一个真实 `Simulator`，整场进度与当前 `GameSession` 分开装配，负责物理推进、规则裁判、版本与去重、唯一一次权威触球。
- 检查点恢复必须保留整场身份、版本顺序和命令原裁决；不继承连接/瞄准显示/旧进程时钟。未完成动作不能通过导出稳定检查点被丢弃，数据库与正式重连另行接线。
- 房间码不能代替整场身份；状态版本与事件序号跨局单调，局结果、准备与整场结果由服务器提交，客户端不得提交胜者或局分。命令缓存按席位隔离。
- 只允许依赖 `src/core/**`、`src/net/**` 与 Node 内置模块；禁止导入 DOM、Babylon、浏览器表现层或数据库/账号 SDK。`core` 不得反向依赖本目录。
- 传输（WebSocket、开发令牌、延迟/故障注入）与裁决分离；延迟注入不得阻塞物理循环或改变房间结果。
- 广播给观看方的出杆参数必须来自服务器已校验、冻结的计划；瞄准姿态须校验球权、阶段、版本、有限值和频率，且不能推进规则/物理/事件版本；显示消息不能再次施加冲量，协议结构变化须同步版本与客户端回归。
- 对局调度及协议时间戳统一使用进程单调时钟，不用系统墙钟推进物理、准备触球或pong校时；日期时间只用于日志/持久化。必须覆盖系统时间调整下的传输回归。
- 开发入口使用开发令牌；玩家入口必须注入可信会话校验，按服务器身份绑定席位，禁止回退开发令牌或相信客户端自报用户ID。身份HTTP适配不进入房间裁判，不直接查库。房间码不是凭证；房间仍是内存状态，不能冒充长久存档。
- 默认只监听回环地址；公开访问经同源HTTPS反代，只开放玩家入口。开发服务器不能暴露公网。
- 不复制自由球/Miss/900 判罚，不改物理参数、镜头算法或已验收规则；物理台面与调参只读。
- 每房间独立 `MeshBody`/`Simulator`、AI 路线缓存与随机源；模块级共享状态必须先证明不会串扰。

- 网络运动只采集核心真实球位，不复用本地渲染的速度外推；中间采样必须有界，不增加物理步或改变碰撞参数。

- 规则命令复用GameSession公开接口，碰撞音只取真实模拟器事件；声音广播不能改变物理步进或加密快照频率。

## 测试与文档纪律

- 房间裁决用真实 `Simulator`/`GameSession` 与测试台面，不 mock 判分；房间时间由调用方传入 `nowMs`，测试不依赖真实定时器。
- 传输测试用真实 WebSocket 客户端覆盖双客户端、重复命令、两房间隔离与延迟注入；不接受“单页面连接成功”充当联机验收。
- 全量 `npm run test`、`npm run typecheck` 与 `npx vitest run tests/server` 通过后再提交。验收结果写项目状态或原型设计，不把施工日志塞进本章程。
