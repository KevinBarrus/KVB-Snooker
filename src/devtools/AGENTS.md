# 开发工具 · 模块章程

继承[全局章程](../../AGENTS.md)；本文件只保留职责、工作约束和必读入口。

## 职责边界

- 仅 DEV 且 VITE_RULES_TEST 未关闭时由装配根加载，正式构建排除测试入口和预设。
- 通过正式 GameOptions 与初始化命令使用同一规则，不维护测试规则副本，不改核心私有状态。
- 预设数据零 DOM，界面由独立浏览器类型工程检查；测试成绩不得进入正式排行榜。

## 测试与文档纪律

验证完整恢复、已加载配置与未提交选择的隔离；浏览器验证席位/规则，构建验证测试入口被排除。

全量检查与提交规则继承全局章程。新证据写模块依据，功能要求写设计，验收写对应记录；仅本文件的职责或约束改变时更新本章程。
