# devtools · 独立开发测试入口

## 职责边界

- 仅由app.ts在DEV且VITE_RULES_TEST不为0时动态加载；生产构建不包含测试菜单或预设。
- 通过装配根GameOptions准备正式GameSession，不维护规则副本，不修改physics、相机算法或核心私有状态。
- presets.ts为零DOM的固定局面数据；rules-test.ts只管理简单下拉框、加载和重置。DOM由render的tsconfig检查。

## 施工单元状态

- 标准开局、最后一红、清彩，两个USER席位；加载与完整重置共用正式初始化路径。
- 完整重置恢复当前已加载预设，不将尚未加载的下拉选择当作当前局面。
- 首单元验收：321项单测、typecheck、build，Chrome规则测试/关闭开关/AI旁观/回放通过；正式bundle无测试菜单与预设字符串。

## 转写时新发现的怪癖

- 本模块为用户批准的测试扩展，无PCOL对应实现。原有65535自由练习与测试的正式规则不可混用。
- 球号1有15个不同索引；删除红球需按索引处理，保留六颗彩球的固定球号。

Node验证预设和完整恢复；浏览器验证两个席位、计分、选择与重置；开发关闭与生产构建验证入口不存在。
