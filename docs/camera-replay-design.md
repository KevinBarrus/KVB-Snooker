# 击球观察模式与上一杆回放

> 状态：需求文档先行提交，三个单元已实现；最终验收记录见下文。
> 日期：2026-10-24；回放实施更新2026-10-25
> 基线：c9fc7e5，293项测试、typecheck、Chrome controller 验收通过。

## 1. 目标与已确认边界

大力薄球碰撞后，原有注视点持续追随高速母球，容易产生急促转头感。本次增加观察模式，改善实时观察，并接入上一杆回放。

默认“自然起身”以用户认可的原版观感为目标：自然抬高、后退，不明显追逐任何运动球。原作源码仍包含缓慢 follow，不能把本次稳定注视策略标为原作逐行转写。原作事实继续保留在 spec04；本文件记录用户批准的体验扩展。

三种模式共享现有身体/头部起身位置轨迹、跟杆后0.5秒等待、1.2秒基础过渡和距离修正。模式只改变视线焦点，不改变击球、物理、规则、站位和起身高度。跟随模式也必须自然抬高、后退。

## 2. 观察模式

| 内部值 | 提示文字 | 行为 |
|---|---|---|
| natural | 自然起身 | 默认。出杆时确定稳定观察区域，随起身平滑看向台面、站直时同步到位，不使用运动球实时中点，不随碰撞变向 |
| cue | 视线跟随母球 | 持续观察母球，允许偏离中心，接近画面外围时加强跟随，抑制突然甩头 |
| object | 视线跟随子球 | 首碰前轻随母球，首碰后连续交接给该子球；之后不因连锁碰撞换目标 |

目标失活、落袋或出界时保持最后的台面观察点，不向袋底追踪，不突然切换其他球。稳定观察区域、跟随响应参数通过大力薄球绕台、K球、直球与长台验收；不能用静态截图代替动态检查。

跟随采用随时间推进的平滑响应，限制转向突变，同时以画面内偏移衡量是否需要加强响应。目标不是逐帧钉在正中央，也不能因固定的低速上限长期掉到画面边缘。三模式切换从当前实际视线接续。

## 3. 操作与偏好

- V 顺序循环：自然起身 → 视线跟随母球 → 视线跟随子球。核查现有输入表后使用86键码；不覆盖已有功能。
- 每次切换短暂显示准确的中文模式名。保存偏好，刷新与新局后沿用；缺失、非法或不可访问的存储回退自然起身，不影响游戏运行。
- 球运动期间允许切换，平滑过渡。子球尚未确定时不猜测目标。
- 玩家主动拖动观察立即手动接管；松开后本杆不自动抢回。再次按V重新启用所选自动观察；下一杆恢复保存的模式。
- 手动接管不覆盖保存的偏好。加塞拖拽与手中球放置不误当作观察接管。
- 回放期间复用V观察切换与手动接管，不让操作穿透到真实对局。

## 4. 上一杆回放

- 摄像机图标进入上一杆回放；无完整记录时不可用。
- Space成功发起出杆时立即隐藏并禁用入口，从后拉阶段即生效；不能等到物理触球。
- 本杆动作与模拟结束并完成记录后重新开放入口。新局清除旧记录。
- 第一版提供播放/暂停、正常/慢速、重播与退出；回放内Space播放/暂停、Esc退出，V切换观察对象。原作C相机切换语义先核对，避免擅自复用为现有清塞。
- 默认使用原作固定全台斜俯视机位；按V后在同一机位切换观察焦点，拖动仍可手动观察。重播或拖动进度恢复全台视角，避免沿用上一播放位置的目标锁定。
- 录制已经发生的球显示姿态及相机/球杆动作，不重新计算另一条物理轨迹。记录只保留上一杆；限制记录规模，超限不发布不完整回放。
- 播放期间暂停真实对局与AI调度，不调用真实Simulator的stroke/step/restore，不改变分数、回合权、随机序列和待击球状态；退出恢复原来的画面与输入。
- 复用已有逆向记录，并在实现前读取 analysis/1.chunk.js 的回放按钮、录制、MovieClip与播放控制源码，补齐行号与怪癖。原作文件和取证中间产物不提交。

## 5. 分层与契约

- controller：击球观察策略、平滑焦点、手动接管、录制与播放状态。通过Simulator的现有只读视图与getResult读取球数据；不读取World/Body，不导入ui/render。
- ui：模式短提示、回放按钮与播放控件。沿用状态类与DOM视图分离；接受装配根传入的状态与回调，不导入controller。
- render：继续消费getBallCount/getBallView结构视图，由装配根选择实时或回放快照，不感知回放控制器。
- app.ts及拆分装配文件：偏好存储、输入路由、录制时机、显示源选择、真实对局暂停和恢复。浏览器存储只在装配根访问。
- 不增删architecture §3事件或§4.2核心接口。新增表现层接口及装配回调在architecture中登记；回放数据采用独立快照，禁止借用核心可变引用。
- 不引入依赖库，单文件≤400行，TS strict、禁any/as unknown as；修改模块同步AGENTS.md。新增策略如非原作算法，不伪造PCOL出处注释。
