# 对局语音

状态：范围已讨论，独立于基础联机的工程提案，未实现。本文不定义文字聊天或录像录音功能。

语音限定同房间双方，主动开启、请求麦克风授权，提供静音、对方音量、说话指示和连接状态。默认不录音，不进入高光。按键说话需先检查既有快捷键冲突，键位尚未冻结。

采用 WebRTC 的方案需具备 HTTPS、经过房间鉴权的信令与可用的 STUN/TURN 服务。游戏 WebSocket 负责授权或转发信令，不把音频帧塞进核心对局事件。凭证放在服务端，TURN 凭证应有期限。

语音连接失败、拒绝麦克风或静音不阻止对局；离开房间释放媒体设备与连接。首批在大陆不同网络测试直连和 TURN 中继，再按实际地域扩展，不承诺所有网络无需中继。

验收包括未授权不采音、静音生效、重连无重复播放、离开停止采集、语音故障不阻塞击球。部署方案、费用和供应商在实施前提出，本轮不采购或部署服务。
