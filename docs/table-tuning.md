# 球台手感调校

2026-11-03，用户批准在 PCOL 基线上初步增强走台距离、侧旋保留和普通库边吃塞效果。此调校是项目扩展，不是原作还原修正。

## 修改入口

只编辑 `src/core/physics/table-tuning.ts` 中的 `TABLE_TUNING`。上面的 `PCOL_TABLE_TUNING` 保存原始值，留作对照，不修改。

| 参数 | PCOL | 初版 | 含义与调整方向 |
|---|---:|---:|---|
| `clothSlidingFriction` | 0.15 | 0.15 | 台面切向接触摩擦。影响滑动向滚动转换和高低杆效果；不是控制滚动距离的独立旋钮，本轮不改。 |
| `clothRollingFriction` | 0.013 | 0.012 | 地面接触的滚动摩擦冲量系数。减小通常使球滚得更远；它不是每秒速度减少量。 |
| `cushionFriction` | 0.15 | 0.18 | 普通硬库切向冲量上限。提高可增强强侧旋的吃库作用；接触未达到摩擦上限时，提高不一定有效。 |
| `cushionRestitution` | 0.92 | 0.94 | 普通硬库法向速度恢复系数。提高使碰库后法向速度保留更多；不是总速度或能量的保留百分比。 |
| `angularRetention` | 0.99 | 0.992 | 每次 `predVelocities` 调用后的角速度保留倍率。越接近 1，旋转衰减越慢。作用于全部旋转轴，同时影响侧旋、高低杆和滚动。 |

角速度衰减沿用原作调用时机，并非按渲染帧或秒直接扣减；碰撞子步也可能调用速度预测。第一版只调倍率，不修改该算法。

## 建议微调方法

一次只改一个值，用相同球位、方向、击点、力度进行比较：

- 走台仍短：先将 `clothRollingFriction` 每次减少 `0.0005`。
- 近库强塞明显、远库强塞不足：先将 `angularRetention` 每次提高 `0.0005`。
- 到库仍有强侧旋但偏转不足：将 `cushionFriction` 每次增加 `0.01`。
- 不加塞碰库后掉速偏大：将 `cushionRestitution` 每次增加 `0.005`。

建议第一轮探索范围：滚动摩擦 `0.011–0.013`，旋转保留 `0.990–0.994`，硬库摩擦 `0.15–0.20`，硬库恢复 `0.92–0.96`。这是游戏调校范围，不是实测球台材料参数。不要把倍率改到大于或等于 1，也不要把摩擦改成负数。实际接触恢复系数取球与库两侧较小值，球侧仍为 `0.985`。

保存后刷新整个浏览器页面并新开一局，再试打；部分值在球体、碰撞多边形构造时读取，不能依赖热更新让旧对象全部同步。运行已有构建时需要重新 `npm run build`，无需重新准备资产。

恢复原作参数：把生效对象替换为这一行，保存并重新加载：

```ts
export const TABLE_TUNING = { ...PCOL_TABLE_TUNING };
```

修改后运行 `npm run test` 和 `npm run typecheck`。单独看对比测量：`npx vitest run tests/unit/table-tuning.spec.ts`。若退回原作或有意降低效果，增强方向的比较断言会失败；应先检查测量是否符合新目标，不要盲目放宽断言。

## 生效范围与分层

- 所有球共用参数；经典、900、自由练习和双人测试使用同一物理配置，不在规则分支中改物理。
- `constants.ts` 的 `PHYSICS` 继续保存 PCOL 常量。台面/硬库构造时由配置覆盖相应材料值；`Body` 从配置读取旋转保留；`ContactSP.startResting` 只给 ground 接触使用新的滚动摩擦。
- 软库、袋口、通道及球球材料值保持原值。接触池从地面复用到其他表面时恢复原滚动摩擦，防止参数串用。
- 真实击球、预测和 AI 模拟消费同一物理实现。原辅助线在首碰后简化场景的行为不变，不新增多库预测功能；AI 既有几何路线启发式也未重调。
- 球面红点仍只读取 `BallView.renderOrientation`。物理旋转变化自然反映到材质，不另加视觉旋转倍率，不修改 Kimi 的 shader。
- 此配置不写进旧存档格式；不同参数下重算同一杆可能得到不同轨迹。调参后应新开局，不以旧参数存档重算结果作为同版本回放基准。

## 初步验证

`tests/unit/table-tuning.spec.ts` 提供可复跑的对比。使用半径 `0.02625`、质量 `1.5` 的球与无库大平面，初速度 `3 m/s`、相应滚动角速度及 `100 rad/s` 侧旋：

| 测量 | PCOL 基线 | 初版 |
|---|---:|---:|
| 最终行程 | 11.149 m | 13.322 m |
| 60 步后侧旋（约 1.002 秒） | 54.716 rad/s | 61.759 rad/s |
| 最终正常休眠 | 是 | 是 |

独立的理想硬库接触测试，法向入射 `3 m/s`、侧旋 `±300 rad/s`：反弹法向速度幅值由 `2.76` 变为 `2.82 m/s`，侧向速度幅值由 `0.864` 变为 `1.0476 m/s`；左右塞对称，中杆不凭空产生侧向速度。此测试用于隔离库边响应，不代表完整真实库面几何。

全量单测和类型检查通过。上述结果证明调整方向及基本稳定性，不等于比赛球台实测标定，也不保证任意线路都能七库。最终手感、真实球台多库线路及 AI 走位效果仍需人工试打验收。
