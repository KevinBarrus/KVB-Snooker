# 经典规则扩展与双人规则测试

状态：现有经典规则扩展的行为说明，2026-11-07 合并旧轮次修订。900 使用独立 [规则设计](snooker-900-design.md)；本文不决定正式联机的暂停、重摆或整场存档。

## 1. 来源与边界

PCOL 事实见 spec/05 和 analysis/1.chunk.js L12703–12822。提名、自由球、贴球、普通犯规选择与简化 Miss 是项目扩展，相关规则对照 [WPBSA 2024–25 规则册](https://wpbsa.com/wp-content/uploads/2198_WPBSA-Rulebook-2024-25.pdf) §2.12/17、§3.3–8/10–14；不宣称已覆盖完整官规。

人机、开发双人和未来联机复用同一裁判。自由练习保留原有随意击球与复位行为，不为测试复制另一套规则或更改物理。

## 2. 提名与接触

自动彩球提名按击球方向、目标角尺寸、遮挡及歧义判断，是意图提示，不是从实际首碰倒推目标。明显目标不打断，歧义、翻库或贴彩球时手选；手选优先，出杆前冻结，不受辅助线显示长度限制。AI 使用路线目标元数据。

贴合法目标球打离可满足首触义务；贴非目标球不自动构成新的非法首触，但仍须击中合法目标。判推杆依赖杆前接触与实际直接冲量，不能用最终位置微移或动画杆尾判断。首次同时接触的合法性按真实接触组裁决。

提名与贴球算法证据见 [规则模块依据](modules/core-rules.md)，接口及数值契约见架构。中央贴球消息的语言、过期、× 和去重只在 [UI 设计](ui-design.md) 维护，不再保留“直到出杆才消失”的旧要求。

## 3. 自由球

犯规后结算及归位完成再检查合法目标两侧极边是否受阻，手中球须检查整个 D 区。自由球不要求先判 Miss，不由相机可见性决定。

资格与提名分开，默认不用，使用时明确提名非目标球。首碰提名球或与目标同时首碰；提名球按目标值计分，进袋后复位。红球阶段真红与自由球得分可累加；清彩同时进袋只计目标一次，仅进自由球不推进目标阶段。

再次用自由球做斯诺克的限制和两彩球例外按规则实现；红黑不能套用两彩球例外。接手保留资格，让犯规方继续或 Miss 复位撤销本次资格。AI 当前不新增自由球策略搜索，仍解原目标。

## 4. 普通犯规与简化 Miss

普通犯规罚分先入账，等待非犯规方选择自己接手或让犯规方从当前位置继续。待选择时不启动下一杆，重复选择不重复罚分。

Miss 的项目简化标准：未完成合法首碰，且击球前及判罚后双方都不需要罚分才可判 Foul and a Miss。分差等于台面可得分仍可追平，超过才排除；可得分包括每颗红后的彩球机会及最后一红后当前彩球机会。

合法贴球打离视为完成首碰。未合法首碰兼母球摔袋仍可能是 Miss；合法首碰后摔袋不是 Miss。未加入是否尽力、故意、完全无解或连续三次失败判负的完整裁判。

有 Miss 复位权时追加原位重打。共用杆前恢复保存球位、姿态、在台状态、目标阶段和球权；恢复保留罚分、杆数及累计统计，不恢复被打断的单杆，清理旧结果、提名、自由球和派生缓存。彩球阶段可以重新提名。

练习可以复用上一杆恢复能力，但按钮尚不在本轮交付范围。它不是多步撤销、开发完整重置或联机协商重摆；后者见 [生命周期](match-lifecycle-design.md)。

## 5. 终局与开球

经典末黑按合法得失分及罚分处理终局；平分则重摆黑球，由本局非开球方从 D 区先打，取消旧抽签选择。争黑不消费下一局开球序列。

既有本地正式对局 reset（包括旧“重新开始”）交替先手；练习与预设重置不消费序列。正式联机的整场换局和双方协商重摆是另一层操作，分别按 [联机流程](multiplayer-design.md) 和生命周期管理，不把本地 reset 的轮换直接套给同局重摆。

## 6. 开发测试入口

DEV 且未关闭 VITE_RULES_TEST 时提供双 USER、规则选择、测试球局、加载和完整重置；生产构建排除。已加载配置与下拉框尚未提交的选择分开，重置恢复前者。

预设包含标准开局、最后一红、清彩及黑球平分。黑球平分为双方 0:7、玩家 1 击打简单直线黑球，合法进球触发 7:7 争黑。完整重置恢复预设的球位、姿态、比分和统计，不把物理 evolution 当比赛数据。

核心只接受正式初始化参数，不能依赖 devtools；规则预设的成绩不进入正式排行榜。公开初始化签名在架构 §4.5–4.6 维护。

## 7. 验收与历史

以真实模拟器回合和最小判分用例组合验证，手工修改 v/w 必须置脏；覆盖合法/非法首触、同时接触、提名冻结、自由球计分、D 区可达、Miss 分差边界、摔袋兼 Miss、复位保分、越权拒绝、争黑和预设隔离。

浏览器验证按钮、真实摆球、消息与焦点、双方席位和生产排除，回归练习/AI/镜头/回放。运行命令见开发操作。
