# 我的球形：创建、管理与自建练习

状态：2026-11-08 已实现。本文维护「我的球形」的数据、创建/编辑流程、回收站和自建球形练习规则。预设球形仍以[练球球形设计](practice-shape-design.md)为准；菜单导航见[菜单设计](menu-design.md)，公开接口登记见架构 §4.11。

## 1. 范围

- 玩家创建、编辑、重命名、删除、恢复和练习自建球形；删除进入回收站，保留 30 天。
- 创建/编辑使用空台编辑器，可摆放红球和六颗彩球；母球不属于自建布局，开练时全台手摆。
- 自建球形练习不采用一红一彩规则：任意球合法，按球面值累计分数与单杆。
- 不涉及账号、数据库、云同步、排行榜、分享或联机。存储使用浏览器 `localStorage`。
- 不改动物理、碰撞台面、相机算法、预设球形生成或正式对局规则。

## 2. 数据与存储

### 2.1 自建球形

```
StoredShape {
  id: string                 // 本地唯一 id
  name: string               // 去首尾空格，1–30 字符，允许重名
  balls: { index, x, z, active }[]   // 只保存对象球 1–21；母球不入库
  createdAt: number          // 首次创建时间
  deletedAt: number | null   // null = 在我的球形；否则进入回收站
}
```

- `balls` 只包含活动对象球；母球、未使用的球不保存。保存时由核心转换成完整 `FrameSetup`（母球默认位置 + 未使用球 inactive）。
- 列表按 `createdAt` 倒序；编辑保存不改变 `createdAt`；恢复保留原 `createdAt`。
- 名称：`trim` 后 1–30 字符（中文/字母都按 1 字符），空名拒绝；允许重名。
- 上限：「我的球形」最多 50 条；回收站条目不占名额。删除立即腾出名额。
- 回收站：`deletedAt + 30 天` 为过期时间，展示 `YYYY-MM-DD HH:mm`；进入回收站页时清理已过期条目，不使用后台定时器。
- 恢复：直接回到我的球形并保留原 `createdAt`；若我的球形已有 50 条，提示「自建球形数量已达上限（50个），无法恢复」，条目留在回收站。
- 彻底删除：二次确认后从存储移除，不可恢复。
- 存储键：`snk.practice.shapes.v1`；读写失败时提示且不丢失已有数据（写入前先解析，异常时停止保存并提示）。

### 2.2 我的球形页面结构

- 固定三块，始终展示：`创建球形`（操作行）、`我的球形`（tab）、`球形回收站`（tab）。
- 点 tab 后对应块高亮，下方展示区切换。空列表文案沿用「当前还未创建球形」；回收站为空显示「回收站为空」。
- 「我的球形」条目：只显示名称，左键弹「是否开始 xx 球形的练习？」，确认框内含经典母球/红点母球选择；取消回列表，确认进入练习。
- 右键「我的球形」条目：编辑 / 删除 / 重命名。
  - 编辑：进入编辑器并加载该布局，按钮为「保存」；保存只弹确认框，不重新命名；保存后回我的球形并保持原排序。
  - 删除：确认后移入回收站。
  - 重命名：输入框，规则同创建命名；确认/取消。
- 右键「球形回收站」条目：恢复 / 彻底删除。左键无反应。恢复直接执行；彻底删除需确认。
- 已达 50 条时点「创建球形」：只弹告示框，无选项，提供 × 关闭。
- 所有弹出框与镜头解耦：弹框期间鼠标拖动/A/D 环绕仍可用，便于观察球台。

## 3. 创建 / 编辑模式

### 3.1 进入与退出

- 从「创建球形」或条目「编辑」进入；进入后清空台面，仅显示当前布局的球，不显示母球。
- 隐藏比分、计时、回放、练习 HUD、球杆、辅助线、摆球提示；保留正常镜头操作（鼠标拖动旋转、A/D 环绕，不做滚轮缩放）。
- 左上角「菜单」变为「退出创建」；点击弹「放弃修改？」确认。无论是否改过都确认；确认后返回我的球形。编辑模式同理，退出不保存。
- 编辑器不是正式对局：不创建 `GameSession`、不推进物理/AI/计时/回放。

### 3.2 球面板

- 底部居中、半透明黑；七种球横排：红球、黄、绿、棕、蓝、粉、黑。
- 球用 3D 小尺寸渲染（不是平面图形），比台面球视觉上更大，类似商城武器展示；数量显示在球下方。
- 初始数量：红 15，其余各 1；已放置数量从库存扣除。
- 点击某一种球：选中（半透明白底 + 小三角），表示手上拿着这种球；再次点击同一种球取消选中。
- 数量为 0 时球上方显示小红叉；仍可点击选中，但台面候选环为橙红色，点击不能放置。放进回收站后数量恢复，红叉消失。

### 3.3 摆放与回收

- 左键台面：若当前有选中球且数量 > 0，在合法位置放下一颗；数量减一；保持选中直到数量为 0 或玩家取消。
- 鼠标移动时显示候选环：合法绿色、非法橙红，与摆球模式的候选反馈一致；合法性 = 台面内 + 不与任何活动球重叠（与 900 全台摆球同一判定）。
- 右键台面上的已放置球：该球下方显示白色旋转环；弹「回收该球？」确认框，两个按钮「回收」「取消」。确认后球从台面消失，对应面板数量 +1，手选状态保持不变；取消只关闭弹框。
- 弹框打开时保持镜头输入：鼠标拖动/A/D 环绕仍可用，方便观察目标球。
- 右键空白区域无任何反馈，不取消当前手选。
- 禁止浏览器右键菜单（编辑器内）。

### 3.4 彩球放点位

- 左侧工具按钮「将彩球放在点位」；点击弹出六颗彩球（只显示球，不显示文字），半透明黑底，每颗球一个矩形区域；可多选，选中背景变半透明白，再次点击取消。
- 已在标准点位的彩球选项置灰且不可选。
- 已在台面但不在点位的彩球可选中；确认后移动到自己的标准点位（原位置清空）。
- 选中的多个彩球按「先移开本次选中的球，再落到各自点位」处理；若点位被本次选中之外的球占用，整次确认失败，提示「有球占用了 xx 球的点位」，不做部分成功。
- 若某彩球尚未放置（在库存），确认后放入其点位并扣库存。
- 成功后关闭弹层并清空选择；取消关闭弹层，不改变台面。

### 3.5 完成创建 / 保存

- 工具按钮「完成创建」：
  1. 弹命名框，输入框限制 30 字符，去首尾空格，空名不能提交；下方「创建」「取消」。
  2. 取消 → 回编辑器；创建 → 弹确认问句「确认以‘xx’完成创建？」。
  3. 确认框取消 → 回命名；确认 → 弹提示「已创建。回到我的球形后点击该球形即可开始练习」。提示框确定后自动回到我的球形列表，新建项排最前。
- 编辑模式按钮为「保存」：点击只弹确认框，确认后写回并回我的球形（保持原创建时间顺序）；取消回编辑器。
- 允许 0 颗球完成创建；进入练习时台面只有母球。

## 4. 自建球形练习

- 启动：从我的球形条目确认后进入，确认框内选择经典/红点母球，沿用现有母球外观逻辑。
- 母球：进入/重摆后全台合法位置手摆。
- 规则：不使用红—彩目标规则，任意球都可击打；不显示目标球阶段，不产生犯规/罚分/换人/犯规弹窗。
- 计分：每颗进袋球按面值累计（红 1、黄 2、绿 3、棕 4、蓝 5、粉 6、黑 7）；连续进球累计单杆，未进球的一杆后单杆清零；母球落袋不计分不扣分、母球回手且单杆清零。
- HUD 只显示分数与单杆，不显示命中率/尝试数/目标球。
- 复位/重摆/退出确认沿用练习模式：复位回滚球位、分数、单杆；重摆恢复初始布局并清零；退出确认。
- 清理完成：仅当「开始练习时台面有球，且最后一杆把最后一颗对象球清掉」时弹出完成选项：重摆 / 复位 / 继续 / 退出。
  - 重摆：恢复该球形初始布局，分数/单杆清零。
  - 复位：回到最后一杆前，球位/分数/单杆回滚。
  - 继续：关闭弹框，保留当前台面、分数与单杆；允许继续操作/空打/查看，之后自行从菜单重摆或退出。
  - 退出：回我的球形列表。
  - 弹框期间保持镜头操作；不锁死相机。
- 预设球形也补同样的「清完」四选项；五分点因自动重摆不触发。清彩原“完成”提示替换为该四选项。

## 5. 接口与分层

- `src/core/practice/custom-shapes.ts`（拟）：纯数据与转换——`StoredShape` 类型、名称校验、上限/回收期常量、`toFrameSetup(shape, simulator)`、`toPracticeOptions()`、回收站过期判断；不依赖 DOM 或 localStorage。
- `src/app-my-shapes.ts`（拟，装配根）：`localStorage` 读写、增删改恢复、50 上限、过期清理；返回只读快照与变更后的新快照。
- `src/ui/my-shapes-*.ts`（拟）：列表/回收站 DOM、编辑器面板、命名/确认/回收/点位弹层；只接受状态与回调，不直接读写核心 World。
- 编辑器装配根负责：清空/恢复台面快照、摆放预览、右键拾取、镜头控制、HUD 隐藏；不创建 `GameSession`。
- 自建练习继续使用 `GameSession` + `FrameSetup`，但需要新增“自由计分”练习选项或在装配根统计进袋分值；正式规则、预设球形行为不变。
- 菜单 `GameMenu` 增加我的球形/回收站状态与条目快照；`MatchLaunchRequest` 增加自建球形启动标识（建议 `customShapeId`），不把完整数据塞进请求。

## 6. 验收

自动：
- 核心：名称 trim/长度、上限、回收期、过期清理、布局转换、恢复时间排序、自建练习计分与单杆（含母球落袋/复位/重摆）。实际 `tests/unit/my-shapes.spec.ts` 6 项通过。
- 浏览器：创建空台→摆球→点位→命名→回列表→开始练习；右键回收球与白环；50 上限告示；编辑保存；删除/恢复/彻底删除；过期清理；自建练习任意球计分、单杆、清完四选项；预设球形清完四选项。
- `npm run test:my-shapes`：真实浏览器创建/摆放/回收、彩球点位、命名完成、自建练习、清完四选项、编辑保存、删除/回收站/恢复/彻底删除、50 个上限告示、预设清彩清完四选项。
- 本轮实测：`npm run test` 73 文件 660 项通过；`npm run typecheck`、`npm run build` 通过；`npm run test:practice`、`npm run test:my-shapes`、`npm run test:controller` 通过。

限制：
- 仅本机浏览器存储，清缓存会丢失；不做账号同步。
- 3D 球面板当前用 CSS 球面高光近似；如需与台面球完全一致的小尺寸 3D 渲染，需后续加渲染缩略图。
- 写入 localStorage 失败时的提示仍未细分；当前存储异常不会写坏已有数据，但不会弹出专门错误提示。
- 2026-11-08 反馈修正：选中球后立即显示候选环；回收/点位确认后恢复画布焦点以保持 A/D；创建成功提示增加「返回」按钮；自建练习使用 65535 任意球目标避免橙红环；自建练习菜单移除暂停、补回复位按钮；回收对话框打开时隐藏候选环；创建球形改为按钮样式；彻底删除后回收站列表立即刷新。
- 2026-11-08 二次反馈修正：回收取消时清除白环；自建练习只在首次进入和母球摔袋后打开手中球白环，普通击球后不再自动打开。
- 2026-11-08 三次反馈修正：编辑模式退出按钮改为「退出编辑」；打开右键菜单时先关闭开始练习询问框；音频改为出杆前主动恢复上下文，不再按事件排队，并在更多用户手势上尝试解锁。
- 不实现分享、导入导出、跨设备同步、回收站之外的管理员操作。
