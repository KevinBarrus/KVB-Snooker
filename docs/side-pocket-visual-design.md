# 中袋皮口与皮裙：第一轮几何修整

## 范围与依据

2026-11-12 用户确认的外观改动。参考本地 `img/图一.png`、`图二.png` 和真实球台 `图五.png`；图片不入库。图三、图四用于后续底袋比较，本轮不调整底袋、网袋、灯光、摄像机、物理袋口或整张球台造型。

本轮追求比例和连续曲面，不声称从照片取得了真实球台的精确尺寸。原球馆保留。

## 原结构与问题

坐标为米：X 沿长边，Z 沿短边，Y 向上。程序先生成 +Z 中袋，再镜像到 −Z。台呢面 Y=0.880，木框顶 Y=0.9205；木框内边 Z=0.951，扶手宽 0.090。木框在中袋左右原来截于 X=±0.0789。

`Pocket` 是六袋共用的皮革网格；`Frame`/`FrameGold` 是木框/金饰；`PocketNet`、`PocketLiner` 分别是透空网袋与暗色内衬。`TableInner` 是台呢和库边。各网格独立，皮革不参与物理碰撞。

原中袋内侧由半径 57 mm 的圆弧与两侧短段组成，圆心为 (X=0,Z=0.9665)，随后按现有 `JawShift` 对齐显示轮廓。外侧却是一条 Z=1.041 的直线。内外轮廓之间铺面后，两端形成约 88 mm 深的皮革肩部，覆盖了几乎全部木扶手宽度。皮裙沿这条直线垂下，宽度基本不变，只有 3 个下垂分段，造成矩形板状外观。

三个尺寸不能混用：

- **覆盖深度**：皮革沿 Z 包覆木框的长度，本轮修改。
- **皮口横向轮廓**：皮革及木框在 X 方向的外观尺寸，不等于球的通过宽度。
- **物理喉宽**：`TABLE_GEOMETRY.middlePocketWidth`，本轮保留当前 102 mm 值；不修改碰撞数据和台呢袋角。

## 实现与调节位置

中袋单独在 `src/render/side-pocket-leather.ts` 生成，底袋仍走原 `pocket-leather.ts` 截面。`buildLeather` 的调用方式和材质不变。

| 参数/形态 | 当前含义 |
|---|---|
| `SHOULDER_DEPTH` | 木框内边至皮口外轮廓端点的深度，18 mm；不是物理喉宽 |
| `BACK_INSET` | 皮口外轮廓中央相对木框最外边的退让，6 mm |
| `THICKNESS` | 皮件表面沿法线向背面形成的厚度，2 mm；侧边和下缘封口 |
| `DROP` | 皮裙中央下垂的基础长度，98 mm；两侧较短，逐渐收束 |
| `sidePocketOuter` | 连续弧形肩部，替代原矩形外边；上表面、圆卷边、皮裙共用边界 |
| `sidePocketWoodEnd` | 两侧木框端部沿弧形皮口局部伸入，保留可见木质肩部；不改变远处扶手宽度 |

皮裙有轻微向外的鼓曲、下部收腰、对称的圆滑下缘。皮口顶面中央稍低，袋内皮壁略向后弯，避免单块平直皮面。袋内下沿仍沿用原轮廓与高度，与既有网口保持原来的衔接；本轮不靠挪网袋或增加亮度改善观感。

仅缩小皮件会露出原木框的开放端面，因此 `table-frame.ts` 同时补齐中袋两侧的局部木质接头。四个底袋皮件、整台台呢、网袋和内衬均保持原几何。底袋第一人称遮挡、网袋形态留给后续独立施工。
