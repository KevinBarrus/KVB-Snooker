# 练球球形：预设布局与练习流程

状态：2026-11-08 已实现。需求来源为用户写入的 [练球模式球形预设需求](practise.md)；本文维护实现算法、练习行为、接口边界与验收记录。菜单导航仍由 [菜单设计](menu-design.md) 维护，公开接口登记见 [架构](architecture.md) §4.9。

## 1. 范围

- 本轮实现十个预设球形的确定性摆球、菜单真实启动、全台自由摆球、重摆、复位、犯规选择、清彩与五分点的不计分规则。
- 「我的球形 / 创建球形」仍是占位，不做编辑器、命名、保存或分享。
- 不改变物理、碰撞台面、相机、回放、经典规则判罚或正式对局流程；球形练习复用同一 `Simulator`、`GameSession` 和规则裁判。
- 不涉及账号、存档、排行榜或联机。

## 2. 球形生成

新增 `src/core/practice/**`，纯核心代码，不依赖 DOM/Babylon/网络。生成器从真实台面碰撞网格读取库边内沿与彩球标准置球点，不写屏幕像素坐标，不随机。

- `table-geometry.ts`：从 `Simulator.ground` 的轴向库边求出球心合法范围，并读取 22 个标准置球点。
- `layout-reds.ts`：蛇彩、S、T、Y。
- `layout-mixed.ts`：订书钉、X、金字塔散点、双龙、清彩、五分点。
- `shapes.ts`：球形 id、布局合并为 `FrameSetup`，并给出练习选项。

坐标和单位沿用用户需求文档：d 为球直径；实际落球使用球心坐标，所有位置由球台几何与标准点位推导。

### 2.1 当前参数

| 球形 | 红球 | 实现 |
|---|---|---|
| 经典蛇彩 | 15 | 黑—底库 3、黑—粉 5、粉—蓝 7，各区间等分，严格在纵向中线 |
| S 球形 | 15 | 蓝→粉、粉→黑两段三次贝塞尔曲线（横向鼓出 7d），按弧长等距取 8 + 6 颗，黑球下方偏左 1 颗 |
| T 球形 | 15 | 粉球为交点；5 颗在粉—黑之间等分，横梁左右各 5 颗使用同一间距 |
| Y 球形 | 15 | 主干 5 颗等分蓝—粉；两翼各 5 颗沿 45°，球心间距 1.8d |
| 订书钉 | 15 | 横梁左右各 4（间距 1.8d），两侧竖直向下各 3；黑球后方中线独立 1 颗 |
| X 球形 | 15 | 粉球中心，45° 斜线左上/右上 3、左下/右下 4（间距 1.8d）；右侧长库旁 1 颗按离库 3.5d |
| 金字塔散点 | 15 | 粉球为顶点，向黑球 1+2+3+4 连续相切三角；外围 5 颗：左侧远处 1 颗、黑球与三角之间左右各 1、近底库左右各 1；黑球下方两颗与上方两颗同 z 对齐 |
| 双龙球形 | 15 | 粉—黑之间两排 8 + 7，排内 1.0d 紧密，排间中心距 1.5d，纵向错开半颗 |
| 清彩练习 | 0 | 六颗彩球在标准点，目标从黄球开始 |
| 五分点练习 | 0 | 只留蓝球与母球，母球默认放在空出的绿球点 |

所有布局必须满足：球数固定、彩球在标准点、不出界、任意两活动球不重叠、重复生成逐位一致。

## 3. 练习行为

### 3.1 母球

- 除 X 球形外，进入球形/重摆后母球为手中球，可在全台任意合法空位摆放；X 球形首次开球只允许 D 区。
- 普通击球后母球不自动回到手中球。
- 母球摔袋时弹出「重摆 / 复位」选择。五分点是例外：摔袋不弹窗，直接按重摆处理。

### 3.2 重摆

「重摆」复用局内菜单「重新开始」：以保存的球形配置重新 `setMode`，恢复该球形初始布局，比分与统计清零，母球重新进入手中球状态。

### 3.3 复位

- 站内单独提供「复位上一杆」按钮（练习模式常驻、无上一杆时禁用），不放进局内菜单。
- 复位回到上一杆击打前：球位、目标阶段、母球位置/球权、比分、break、杆数统计全部回滚。
- 复位后保留最后一杆回放，回放内容就是被撤销的那一杆。
- 犯规弹窗中的「复位」与常驻按钮共用同一路径。

### 3.4 犯规

练习球形中犯规后弹出只有「重摆」「复位」两个选择的弹窗，弹窗期间锁定瞄球/摆球输入，选择后才恢复；五分点母球摔袋例外（自动重摆）。

### 3.5 计分

- 经典蛇彩、S、T、Y、订书钉、X、金字塔散点、双龙保留斯诺克计分与红—彩轮换。
- 清彩、五分点不计分：核心不累加 `pts/penalty/break`，HUD 隐藏比分；清彩完成全部彩球后提示完成并停止继续瞄准。
- 五分点：蓝球每次进袋后立即回到蓝球点并保持目标为蓝球；母球停在当前位置，摔袋则重摆。

## 4. 接口与装配

- `GameOptions.practice` 只允许练习模式，提供 `cuePlacement`、`respotTargetBallNumber`、`targetBallOn`、`score`；非法值构造即拒绝。
- 练习模式允许 `GameOptions.setup`；`GameSession.reset` 恢复该布局。
- `GameSession.canRestorePreviousShot`、`practiceScored` 为只读派生值。
- `Player.snapshot()` / `restore()` 保存比分、罚分、杆数、命中与最高单杆；仅练习复位消费，正式比赛恢复语义不变。
- 菜单 `MatchLaunchRequest.shapeId` 与 `GameMenu.startShapePractice` 产生启动请求；装配根把 id 映射为 `makePracticeShapeConfig` 的 `setup + practice`。
- `PracticeControlsDom` 承载常驻复位按钮与犯规选择弹窗；`InputGame.locked` 供装配根在弹窗期间锁输入。
- `ScorePanel.visible` 控制不计分练习隐藏比分。

## 5. 验收

自动：

- `tests/unit/practice-shapes.spec.ts`：十种球形的确定性、球数、彩球点位、无出界、无重叠、FrameSetup 合法性、双龙排距与对称性。
- `tests/unit/practice-shape-game.spec.ts`：练习 + setup、全台/D 区摆球、复位回滚球员统计、五分点目标复位与不计分、非法选项拒绝。
- `npm run test:practice`：真实浏览器点击菜单启动十个球形、全台自由摆球、犯规弹窗与复位、复位后回放可用、重新开始重摆、清彩与五分点不计分和五分点绿球点母球。
- 本轮实测：`npm run test` 65 文件 626 项通过；`npm run typecheck`、`npm run build` 通过；`npm run test:practice` 通过（截图写入 `.cache/practice/`，不提交）；`npm run test:controller` 通过。

限制：

- 浏览器验收为软件 WebGL 与同机单页面，不等于用户实机手感；球形几何比例由用户看俯视图与实机试打继续微调。
- 「我的球形」、练习成绩统计面板、存档与分享不在本轮范围。
- 联机房间不启用球形练习；`RoomOptions.frameSetup` 仍是联机开发夹具，不承担练球产品流程。
