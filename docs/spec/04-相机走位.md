## 1. 相机本体（observed）

- Babylon `TargetCamera`（"defCam"，L2096）；fov 0.88，minZ 0.01（模10 顶部配置）
- 初始位 (-4.5, 1.7, 5)；**站姿默认观察位：距台心 3.1、眼高 1.7**（入场动画目标，L3586-3590，`Power1.easeInOut`）
- 相机不自由飞行——一切位置由下述控制器合成

## 2. 双轨道走位系统（horizonCtl，模10 L4550-4640）

玩家绕台移动 = 沿轨道改变方位角 `angle`，身体位置 = 轨道点：

| 轨道 | 参数 | 用途 |
|---|---|---|
| 外轨 track[0] | 椭圆：center=台心(0,0)，radius 2.05，scaleX 1.55（x 向拉长匹配 2:1 球台） | 站立态(STAND)巡视 |
| 内轨 track[1] | 圆：**center=母球位置**（`resetInnerCenter`），radius=innerTrackRadius 0.38，scaleX 1 | 瞄准态(AIM)微调站位 |

### 2.1 角速度模型（带惯性）

```js
orbit(left, right): orbitSpd.to(0.0018 × (right − left))    // 按键→目标角速度（斜坡）
applyAngularSpeed(δ): angularSpd += δ                        // 外部注入（触屏拖动）
update(): angularSpd ×= 0.82（惯性衰减；|·|<1e-4 归零）
  speedFactor = 0.2 × transitionRatio + 0.8
  angle += (1 + scaleX×t − t) × angularSpd × speedFactor,
    其中 t = 1 − |sin(angle)|        // ★椭圆匀速补偿：长轴端自动减速
```

### 2.2 轨道切换与过渡（L4622-4640 + L4540-4548）

- 外→内（进入瞄准）：`ti()` 把当前位置**投影**到内轨；内→外：`ei()` 沿视线推到外轨
- 过渡期间身体位置在两轨控制点间插值（`ii/si` 预计算控制点+变化率），插值比例 = 过渡缓动 renderedRatio
- **距离自适应时长**：控制点位移平方 >4 时 `timeScale = 1 − 0.0125×(min(distSq,16)−4)`——走得越远过渡越慢（最少 0.85 倍速）
- `resetWithKissDir(dx,dz)`（L4593-4608）按给定击球方向的反方向定位内外轨道并清零角速度；原包调用点在 AI 选杆后（L7616），不是玩家击球后自动按分离角重定位相机。
- 玩家激活时才用当时的母球位置重设内轨中心和头部原点（L5762-5772）；击球期间跟随注视点不更新这两个位置。

## 3. 蹲起（verticalCtl，L4646-4676）

```js
eyeStandHeight 1.7, eyeSquatHeight 1.0 → squatDeltaH = −0.7
squatDown/standUp：0.6s Power1.easeInOut 补间（可瞬时 end/pause(0)）
eye.y = 1.7 + (1 − stateRenderedRatio) × squatRatio × (−0.7)
```

`squatRatio` 为蹲姿缓动比例，0=站、1=蹲；`stateRenderedRatio` 为站立/瞄准过渡比例，0=站立、1=瞄准。蹲下用于贴库球低视角观察。

## 4. 状态机（L5666-5686 + 混合逻辑 L5404-5430）

```
STATE_STAND = 0  ↔  STATE_AIM = 1
过渡：_stateTransitionTween 1.2s Power1.easeInOut；stateRatio = uneaseRenderedRatio
事件：sc_start / sc_end / AI_SHOT（AI 击球走同一控制器，发 AI_SHOT）
```

球杆合成（update，L5404-5430）：球杆位置/旋转在两态间插值

```js
l = min(1, ratio/0.9), h = min(1, ratio/0.7)     // 两段缓动曲线
pos.xz 用 ease c=Ii(l)，pos.y 用 d=Ti(l)，rot.z 用 u=Ai(h)
isReadyToStroke() ⇔ stateRatio === 1 && state1.isReadyToStroke()   // 完全进入瞄准态才可击球
```

相机最终合成另见 L7660-7667：`position=lerp(bodyPosition, head.position, renderedRatio)`；注视点为 `lockedTarget + head.lookAtOffset × renderedRatio`。球杆的两段比例不能用来代替相机位置插值。

## 5. 注视与头部（observed）

- **lookAtCtl**（L4676-4776）：注视目标三轴独立离散弹簧（参数 .5/.25/.5，eps 3e-4）。跟随时增益固定为0.05，退出跟随后以0.35秒线性补间回到0.26。弹簧按更新次数推进，不按 dt 归一化。
- **headCtl**：头部姿态由球杆驱动 `setAngles(stickCtl.angleH1, stickCtl.rotationZ1)`——俯仰贴杆、侧头观察加塞线
- **azimuth**：身体朝向斜率由 `target − bodyPosition` 的 x/z 决定（setSlope）

## 6. 击球期间的镜头（L6338-6423）

1. 玩家开始出杆动画时禁用输入并调用 `follow(balls[0])`，物理触球后恢复输入（L6338-6366）。
2. `follow` 只把注视点弹簧的 x/z 目标持续设为母球位置；y 保持台面高度+球半径+0.03，落袋不追踪下落高度（L4702-4776）。不追踪目标球，也不把相机位置平移绑定到母球。
3. 跟杆动画结束后才消耗0.5秒起身等待时间，随后调用一次 `gotoState0()` 并切换到默认更新处理器（L6376-6385）。起身使用1.2秒 Power1.easeInOut 反向补间，轨道距离可降低 timeScale；手动提前起身沿已有过渡继续。
4. 起身期间注视点仍缓慢跟随母球，相机位置独立按身体/头部姿态合成。站姿手动拖动观察或复位注视会取消跟随（L4732-4757、L5815-5830）。
5. 默认处理器在该帧没有活动球步进且起身比例为0时，取消动画、解除跟随并请求裁决（L6396-6422）。`getMotion()<1` 属于预测终止条件，不是这里的停止跟随条件。

因此“自然起身”和“缓慢跟球”在原作中同时存在。复刻不得直接删去 follow，也不能把它实现成相机位置跟球移动。

## 7. 复刻要点

1. 走位手感三要素：惯性衰减 0.82、椭圆匀速补偿公式、过渡距离自适应时长——缺一个都会"飘"或"顿"
2. 内轨以母球为心（半径 0.38）是"贴球瞄准"的关键设计
3. 所有控制器输出最终汇成 bodyPosition/rotation，再交给 stickCtl 合成持杆姿态（见 02 文档 §3）
