## 2. D 区几何（模51 DArea，L12509-12567，observed 全读）

```js
resetWithCenterTopNormal(cx=−1.04, cy=0.88, cz=0, sx=−1.33, sy=0.88, sz=0, normal=(0,1,0)):
  center    = (−1.04, 0.88, 0)          // 开球线中点（baulk line）
  arcDir    = normalize(顶点 − center) = (−1, 0, 0)   // 半圆凸向 baulk 侧（x 负向）
  radius    = |顶点 − center| = 0.29     // ★ = 292mm，真实斯诺克 D 半径 292mm，毫米级吻合
  diameterDir = normal × arcDir = (0, 0, 1)
  diameterA/B = center ∓ radius × diameterDir   // D 直径端点 z=∓0.29
geoCenter = center + 0.5×radius×arcDir = (−1.19, 0.88, 0)   // 镜头自动看向的点
```

合法性判定 `projectionInside(p)`：`p−center` 与 arcDir 同向（**x ≤ baulk 线一侧**）且 `到 center 距离 ≤ radius`（投影到台面平面）。即官方"D 区 = 开球线与底库间半圆"。

## 3. 交互全链路（模10 inHand 子控制器 `je` 类，L4177-4345，observed 全读）

### 3.1 进入方式

- 底部快捷条 "pick up" 按钮（`shortcutsBar.allowPickUp(轮到你 && inHand>0)`，L6257-6260）或快捷键 **P**（keyCode 80 | ESC 27 组）
- 触发 `SWITCH "inHand"` 事件 → 控制器子组切换（L7760 注册，L8027 路由）
- **进入时的动作**（activate，L4253-4275）：
  1. `showRespotIcons(当前母球位置)`——母球原位出现**旋转白色光标**（respotIcon0，0.11×0.11，alpha 0.75，自旋动画 `_icon0Angle += 0.06`，L1854-1918）
  2. 其余玩家控制器全部失活；`fpc.gotoState0()`（站姿）
  3. **镜头自动对准**：首次视口朝向与 D 区 geoCenter 方向 dot < 0.84 → `lookTo(geoCenter)`（L4303-4308）；10 秒无操作自动补一次提示 tip + 再 lookTo

| 输入 | 效果 | 绑定 |

| `A/D` 或 `←/→`（65/37 与 68/39） | 沿外轨道站位（ orbit(±1)）——走位系统照常可用 | L4186-4203 |

### 3.3 放置校验（流程管理器，L3725-3735）

```js
reqRespotCueball(spot, sim):   // gState 必须 READY
  projectionInSideValidRegion(spot)      // 在 D 半圆盘内+台面内（模型层最终校验）
  && spot.y = spotY(台面放球高度)          // y 强制归位
  && !sim.touchBalls(0, spot)            // 与任何球间距 > 1.05×round（规格 05 §4 同参）
  → respotIndexXYZ(0, x, y, z)           // 母球瞬移
  → gContext.inHand: 2 → 1
  → _response: 快进结算 → 快照 → READY
校验失败：直接 _response（无变化），点击层已被绿色预览过滤，服务端仅兜底
```

### 3.4 退出方式

- **P / ESC**：`SWITCH "gaming"`（回到常规控制，母球不动）
- **W / ↑**：退出并同时 `gotoState1()`——放好球直接摆出瞄准姿势（L4210-4216），比赛常见连招"摆球→俯身瞄准"一次完成
