## 总体架构

```
index.js（启动器）
 └─ 浏览器/设备检测 → 桌面端 + WebGL 通过 → 加载 chunk 0 + 1
     └─ module 10：new Game().launch({ PLAYER 1 })  ← 纯单机，无服务端

1.chunk.js = 85 个模块（M10–M94）
 ├─ 自研物理引擎（非开源库！）：数学库 + 刚体世界 + 碰撞体
 ├─ 自研渲染材质：IBL 光照着色器（画面好的核心原因）
 ├─ 游戏核心 M10：8778 行，89 个类
 └─ M54–M74：图片资源引用（3 行小模块）
```

## 五大关键发现

1. **物理引擎是作者自研的**（1.chunk 全文无 `oimo`/`cannon` 调用痕迹；0.chunk 里的 oimo 字符串与游戏逻辑无关）。
   自研套件：`Vec3`(M12)、`Quaternion`(M23)、`Matrix3`(M15)、`World`/`WorldClient`(M39/M95)、`MeshBody`(M84)、`Sphere`(M36)、碰撞分区扩展 `uv4pg`(M80)。
   → 复刻路线：照读自研引擎的算法与参数，不能拿开源物理库替代。
2. **物理调参常量集中在 M14**（L8932）：`gravity: (0,-19,0)`、`tPrecision: 3e-4`、`islandUpdMinDisSq: 0.1`。重力 -19 ≈ 2 倍真实重力，游戏手感的来源之一。
3. **桌子碰撞体按区域分类**（M80，L13360）：`ground`（台面）/ `sidesoft`（软库边）/ `sidehard`（硬库边）/ `tunnel`（袋口通道）/ `pocket`（袋）——袋口不是"开洞"，是五种碰撞区的组合。
4. **渲染效果来自自定义 IBL 材质**（M31，L10171）：`pcolDyIBL` 着色器 + HDR 环境贴图缓存（`__parseAndCacheHdrData`），含 ACES 色调映射。这是 1:1 复刻画面的关键资产。
5. **第一人称走位模式**（M10 顶部配置，L20-29）：`camera: {fov: 0.88, minZ: 0.01}`、`personController: {eyeStandHeight: 1.7, eyeSquatHeight: 1, innerTrackRadius: 0.38}`——玩家以 1.7m 眼高绕台走动（`innerTrackRadius` 为绕台内圈半径），非俯视 2D 视角。
