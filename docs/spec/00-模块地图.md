## 编号修正记录（重要）

1.chunk 模块数组在 L8500 有一个空槽（module 11 空缺）。已用**括号深度扫描 + Node 语法边界实验**双重验证修正：v1 文档中 L8500 之后的"M10–M94"实际编号 = v1 编号 + 2。命名空间模 13 的导出引用（`Vec3: i(12)` 等）与扫描结果全部互验一致。

**module 11 真身**：不在 1.chunk。0.chunk L2 起的 module 11（61,017 行）= Babylon.js 完整构建。其内部的 CANNON/OIMO 字符串是 Babylon 自带的可选物理插件类（CannonJSPlugin/OimoJSPlugin），**游戏中从未激活**——1.chunk 全文无 oimo/cannon 调用，三处 `i(11)` 引用（模 10/33/79）均为 Babylon API 用法（`s.Effect.ShadersStore` 等）。

## 总体架构（修正版）

```
index.js（启动器：设备/WebGL 检测）
 └─ Promise.all([chunk0, chunk1]) → new Game().launch({PLAYER 1})   ← 纯单机
chunk0 = Babylon.js（渲染引擎，含休眠的物理插件代码）
chunk1 = 作者自研的游戏层：
 ├─ 自研物理引擎：数学(模12,23) + 刚体(模35) + 碰撞体(模36,82,84) + 求解器(模23) + World(模39,95)
 ├─ 自研渲染：IBL 材质(模33) + 自定义材质(模79)
 ├─ 游戏核心模10：8499 行（走位/瞄准/击球/状态机/UI）
 ├─ 规则引擎：犯规枚举(模30) + 判定(模54)
 └─ 游戏定义模96：初始球位/球半径/球质量
```

## 五大关键发现（修正版）

1. **物理引擎为作者自研**（非 Cannon/Oimo；0.chunk 里的引擎字符串是 Babylon 休眠代码）。自研套件：Vec3(模12)/Quaternion(模23)/刚体基类(模35)/Sphere(模36)/MeshBody(模84)/桌面碰撞区(模82)/World(模39)/WorldClient(模95)。
2. **物理常量集中在模 16**（详见 01-物理内核）：重力 -19、双档库边（硬 0.92/软 0.45）、袋 0.002、球-球 0.985、空气角阻尼 0.99。
3. **桌面碰撞体五分区**（模 82）：`ground/sidesoft/sidehard/tunnel/pocket`——袋口是分区碰撞的组合，不是几何开洞。
4. **渲染效果来自自定义 IBL 材质**（模 33，877 行）：`pcolDyIBL` 着色器 + HDR 环境缓存 + ACES 色调映射。
5. **第一人称走位**（模 10 顶部配置）：`camera: {fov:0.88}`、`personController: {eyeStandHeight:1.7, eyeSquatHeight:1, innerTrackRadius:0.38}`。

### 初始球位数据（模 96，直接观察）

`ballSet` 为三元组序列 `[id, x, z, …]`：0 号母球 (-1.04, -0.145)；15 颗红球（id=1）三角阵，首排 x=0.915125，行距 0.045467（=2r·sin60°），列距 0.0525（=2r）；彩球 2/3/4 在开球线 (-1.04, ±0.29 / 0)，5 居中 (0,0)，6 (0.86,0)，7 (1.42,0)。`ballRadius 0.02625`（真斯诺克球 Ø52.5mm）、`ballMass 1.5`（自定义单位）。
