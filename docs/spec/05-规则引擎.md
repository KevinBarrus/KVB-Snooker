## 3. checkResult 判定流（模54 L12703-12739，observed 全读）

输入：`gContext` + 模拟器（`result`：firstKissIndex/pottedIndices/outOfBoundsIndices，见 02 文档 §4）+ 输出 `{score, foulCode}`。

```
1. ballOn === 65535（哨兵）：全部重置彩球 → inHand=1，结束（特殊流程态）
2. 首触球号 a：
   ballOn === COLOR_ALL(252)：
     a ≤ 1（无首触或首触红球）→ foul(MISS_TARGET|ILLEGAL_FIRST_HIT)，罚分候选 o=−7
     否则合法，记 l = a（本杆合法球）
   ballOn 为具体球：
     2^a ≠ ballOn → foul 同上；罚分候选 o = min(−a, −log2(ballOn), −4)   ★最低罚4
3. 出界球（OFF_TABLE）：d = min(−球号, −l, −4)
4. 进袋逐个：球号 === l → 得分累加 r += n
            否则 foul（母球→POTTING_CUE_BALL，其余→ILLEGAL_POTTING），罚分候选 _ = min(−n, −l, −4)
5. score = 三项罚分均为 0 ? r（合法进袋分和）: min(o, d, _)（负罚分）
6. ballOn 推进：
   ballOn === BLACK 且 score>0 → ballOn = 0（终局态）
   score≤0 或 ballOn∈{RED, COLOR_ALL}：
     母球不活跃 → inHand = 2（手中球）
     _liveRespot（彩球归位）
     score>0：RED → COLOR_ALL；COLOR_ALL → (还有红? RED : YELLOW)
     score≤0：ballOn∈{RED, COLOR_ALL} → (还有红? RED : YELLOW)
   score>0 且 ballOn 为具体彩球：ballOn <<= 1        // 4→8→…→128 顺位推进
```

罚分语义与真实斯诺克一致：罚分 = max(违规球分值, 目标球分值, 4)，以负分计入。

## 4. 彩球重置 _liveRespot（L12740-12815，observed 全读）

占位判定半径 = **1.05 × ballRadius**。顺序：

1. **原位优先**：彩球自己的 spot 无接触 → 直接归位，登记占用
2. **高分空位**：未被占用的 spot 按**球号从高到低**（黑→粉→蓝…）试放，`touchBalls` 校验不贴球即放
3. **中线扫描**：仍放不下的球——以该球 spot 的 z 为行、台面 x 两端（内缩 1.05r）为界，用模 32 区间运算找空段，沿 +z 方向步进（最多 10 次），落点取空段内离原 x 最近处（`findClosestTInSections`）；彻底失败则强制原位
4. **母球**：spot 被占 → 在 **D 区**（模51：diameterA/B 端点 + radius + arcDir）沿直径线→弧线扫描空位（步进累计超过半径则放弃回原位），即"手中球自动找空位"

## 5. 有效区域（模51/52/53，observed）

- `_playArea`：由 ground 多边形（JSON，见 03 文档）构建的点集多边形——`projectionInside` 判点在台内（摆球合法性）
- `_dArea`：**D 区**（圆盘），由场景表 `dArea {cx:-1.04, cz:0, sx:-1.33, sz:0}` 构建——cx=-1.04 即开球线位置（与母球初始位、彩球摆位一致）；sx=-1.33 为 D 圆参数（圆心 x 或半径，待精确对齐模51 全文）
- `intersectionRayValidRegionPlane`：射线与区域平面求交（摆球指针拾取用，limit 10）
