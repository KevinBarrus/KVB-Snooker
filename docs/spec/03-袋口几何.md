## 2. 碰撞网格数据格式（observed）

顶层三组：`side`（120 顶点/60 多边形，附 `nt` 法线图名）、`tunnel`（8 顶点/5 多边形）、`ground`（8 顶点/1 多边形）。

顶点数组 `p` 为 xyz 平铺浮点；多边形对象：

```js
{ i: [顶点索引…],        // 多边形顶点
  n: [nx, ny, nz],       // 平面法线（数据自带，不需重算）
  f: ['sidehard'|'sidesoft'|'pocket'|'tunnel'|'end'|'ground'],  // 分区旗标→恢复系数查表(模16)
  s: [cx, cy, cz, r],    // 包围球（宽相剔除用）
  uv: [u,v …]            // 库边贴图坐标（仅 side 组）
}
```

**分区旗标即 restitution 查表键**（模16：ball/ground/sidehard/sidesoft/tunnel/pocket/default）——软硬库不是算出来的，是数据标死的。

### 3.1 台面与库边

- 台面：y = 0.88 的 8 边形，x ∈ [-1.797, 1.765]，z ∈ [-0.897, 0.897]（袋口处缺角）
- 库边鼻线：z = ±0.897（长边），x = ±1.713（短边，见 cushionData.bounds）
- playArea（视觉参考面）：中心 (0, 0.88, 0)，3.66 × 1.859
- cushionData.y = 0.92：库边顶高

### 3.2 六个袋位（由 pocket 旗标多边形质心聚类）

| 袋 | 位置 (x, z) | 喉部小平面质心 |
|---|---|---|
| 角袋 ×4 | (±1.86, ±0.92) 邻域 | (±1.868, ±0.915)、(±1.857, ±0.956)、(±1.817, ±0.969) |
| 中袋 ×2 | (0, ±1.0) | (±0.033, ±0.996)、(0, ±1.005) |

中袋口宽：bounds 轮廓上 x ∈ [-0.028, 0.028]（0.056）；角袋喉部外扩至 x=±1.876 / z=±1.005。

### 3.3 落袋漏斗（tunnel 组）

- 顶点两档高度：入口缘 y=0.8843（与台面齐平），底缘 **y=0.6033**
- 漏斗壁法线倾斜（如 (0, 0.141, 0.990)）——球进喉部后沿斜壁滑向中心
- **落袋判定**（模39）：`ball.position.y < meshBody.lowestPosition.y(=0.6033)` → `inactivateBall` + `outOfBoundsHandler`——球穿过漏斗底缘即消失（无底面阻挡）
- `end` 旗标多边形为外观封底，球在到达前已越界

### 3.4 物理行为闭环

```
球撞库鼻(sidehard 0.92 弹开) → 擦入口(sidesoft 0.45 吃力)
  → 进喉(pocket 0.002 无弹) → 沿 tunnel(0) 斜壁下滑
  → y < 0.6033 → inactivate + outOfBoundsHandler（进袋事件→规则/声音）
```
