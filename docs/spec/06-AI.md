## 2. 候选生成三段流水线（模10 `$t` 类，L2540-2745，每帧切片 ≤20ms）

| 任务 | 逻辑 | 产出 |
|---|---|---|
| 0 进球线 | 目标球×袋：`h=norm(袋−球)`，**切角超袋口开口拒绝**（`h·袋法线 > maxHalfOpen`）→ 进球线段安全 → 幽灵球位=球−(r₁+r₂)h（须在台内）→ 瞄准方向与切角 v → 邻袋遮挡检测（喉部挡道 b=1，**他袋挡道直接放弃** b=2） | 进球路线 |
| 1 安全球 | 沿目标球投影带扫触点偏移（正常 5 档 / 开球 1 档），任一段安全即出路线（priority≈0.1×rand，低优先） | "碰到就算"路线 |
| 2 翻袋 | 遍历 sidehard 库面水平边：镜像反弹几何（法向补偿 `c = r球 + 2×r×a/l`），**两段路均安全**才收；`fbSpin = −力度×(cosθ+1)²`（翻袋自带低杆），`priority = 1 − 距离/10` | 库边反弹路线 |

三段全空 → `_randomRoute`：随机方向、力度 `0.6×rand`、priority `0.05×rand`（解围乱杆）。

开球模式判定（`getIsBreak`，L2649-2660）：目标球全部在 spot 0.05² 内 → 开球参数（触点偏移 2r、力度 0.85+0.14×rand）。

## 3. 进球路线评分（`_checkSinglePK`，L2752-2807）

```js
S = 球袋距/台面对角线      C = 母球距/台面对角线
力度 T  = 0.2×(C+S)/2 + (1−切角v)×S×0.7
优先级 A = (0.5×(1−C) + 0.45×(1−S)) × v + 0.05×球号
// 喉部遮挡(b=1)：fbSpin=−0.99（重低杆防母球跟进），T = max(T, 0.7×C)
```

选路：线性扫 priority 最大者（`step`，L2663-2690）。

## 4. 拟人化误差注入（`_chaos`，L2710-2744）

- 5% 概率零误差（完美杆）
- 误差强度 `f = [min(1, 母球距/range)]² × abf + sigmoid01(袋距 − 1.8×切角², 0.5) × bcf`
- 实际偏移量 = `f × (1 − random^chaoticSeed)`，随机正负，**垂直于进球线**作用于袋点 → 重建幽灵球与瞄准方向
- **中袋（pkIndex 2,3）误差 ×mpm**；小幅误差 ×bpm
- 直觉验证：切角越薄、距离越远误差越大——与真人对袋口精度的感觉一致

## 7. 对复刻的直接结论

1. AI 全部公式已还原（§2-§5），无需机器学习——PCOL 的 AI 是**规则几何 AI**，参数化难度
