## 3. 瞄准几何：从杆到触点（observed，L5090-5310）

1. **cachedProps**（L5091-5115）：绑定球杆规格与球半径，推导 `ballNTipRadiusSq=(r球+r皮头)²`、`maxTipOffset`、`stickLen`
2. **潜在障碍检测**（L5263-5274）：以 `_worTargetPoint` 为中心、`stickLen + r球 + 0.1` 为半径，收集所有可能挡杆的球（排除母球与已进球）和库边
3. **圆锥越障**（L5275-5310）：沿杆轴做锥体检测（锥半径=midRadius）→ 得每个障碍的 `escape` 侧移量：
   - 最大 escape ≤ `_tipMaxEscape`：杆与触点整体侧移（微让）
   - 超限：改为**旋转击球方向**——`angle = acos(方向·径向) − asin(障碍半径/距离)`，与 π/2 取小，绕法线四元数旋转方向向量（模拟真球员抬杆越障）
4. 触点/方向结果经 `onKissPropsChanged(tip.x, tip.y, tip.z, dir.x, dir.y, dir.z)` 回调写进 `_strokeVars[0..5]`（L5716-5727）

```
_launchShot(controller):
```

## 5. 接触求解器（模 21，L9322-9417，observed 全读）

### 5.1 solveContact（单接触冲量求解）

```
输入：接触 c（含法线、restitution、friction、rollingFriction、armI/armJ、双刚体）
1. 相对速度 → 接触空间：s = L2Wᵀ × vRel            （x=法向, y/z=切向）
2. 目标法向速度 r = s.x ≥ bounceThreshold ? −s.x    // 静止接触：直接归零
                                    : −(1+e)×s.x   // 牛顿恢复模型
3. 目标速度向量 (r, −s.y, −s.z) → 冲量空间 d = L2W × (·)
4. 库仑摩擦锥：切向分量范数 t，上限 μ×|d.x|
   t > μ|d.x| 时切向按比例截断          ★旋转传递的上限机制
5. 滚动摩擦冲量 p = d.x × rollingFriction（独立的第二冲量）
6. bi.applyImpulseAtPoint(冲量, armI, p/armLenI)   // 平动 + 扭矩
   isSS 时 bj 施加反冲量（球-球对称）
```

`bounceThreshold = gt · normal`（L9436-9439），其中 `gt = 2.3 × stepSize × gravity`（模22 全局阈值向量）——按接触法线方向动态确定的"低速即静止"阈值。

### 5.2 摩擦系数表（复刻关键参数）

| 接触对 | μ | 物理意义 |
|---|---|---|
| 皮头-球（TipContact） | **0.9** | 塞/高低杆的旋转传递通道，L13658 |
| 球-球 | **0.01**（frictionS） | 近无切向摩擦 → 分离角干净、薄碰少带转 |
| 球-桌面/库边 | **0.15**（frictionP） | 滚动与库边摩擦 |

### 5.3 岛屿迭代求解

```
solveIsland(island):
  for iter in 0..maxIter(=4):
      取闭速度最负(最紧急)的接触求解；全部闭合(≥−EPSILON)则提前退出
  _sloveChildrenPene: 穿透>0 的接触沿法线各退 0.5×穿透量（位置修正）
```

贪心"最紧急优先"而非顺序 Gauss-Seidel；`maxIter = 4`。
