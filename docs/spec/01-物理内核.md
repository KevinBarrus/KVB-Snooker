## 1. 引擎定性

PCOL 使用**作者自研的 impulse-based 刚体物理引擎**，专为台球场景设计（球全是 Sphere，桌面是静态 MeshBody 多边形集合）。**不是** Cannon.js/Oimo.js/matter.js：

- 0.chunk module 11 = Babylon.js 本体，内含的 CannonJSPlugin/OimoJSPlugin 是 Babylon 的休眠可选插件，游戏未激活（1.chunk 无任何 oimo/cannon 调用；`i(11)` 三处引用均为 Babylon API）
- 引擎特征：事件驱动 CCD 子步进 + 接触岛 + 能量睡眠 + 确定性序列化——为"精确碰撞时刻 + 可回放"设计，通用引擎不做这种定制

复刻策略：**照算法重写**，不引入第三方物理库。物理相关的全部模块：模 12(Vec3)、17(3×3 矩阵)、23(Quaternion)、35(Body)、36(Sphere)、37(Contact)、84(MeshBody)、86(TipContact)、82(桌面碰撞区)、21(求解器)、34(岛屿)、22(CCD 辅助)、94(活动接触集)、39(World)、95(WorldClient)、16(常量)、20(统计)。

## 4. World 步进算法（模 39，L11776-12105，observed 全读）

### 4.1 外层：固定步长累加器

```js
stepSize = 0.0167            // 60Hz 固定步长
maxSteps = 10                // 每帧最多 10 个子步
step(dt): accumulator += dt;
  while (accumulator >= stepSize && n < maxSteps) { accumulator -= stepSize; internalStep(); }
```

`stepSize` setter 同时推导睡眠能量阈值（L11791-11797）：

```js
minEnergy    = round(|gravity| * stepSize * (1 - baseSleepBias^stepSize) * 0.5 * 1e3) / 1e3
maxEnergy    = 4.5  * minEnergy
wakeUpEnergy = 1.4  * minEnergy
gt = 2.3 * stepSize * gravity        // 模22 的全局阈值向量
```

### 4.2 内层：事件驱动 CCD 子步进（`__internalStep__`，L12046-12105）

这是引擎的核心创新点。伪代码（变量名已还原语义）：

```
internalStep():
  evolution++                          // 全局演化计数（确定性回放）
  strictMode ? pendings.removeAllSS() : vState基线=SLOWER
  islands.update(actings, true)
  for ball in balls: ball.predVelocities(T)      // 预测整步速度
  solver.solveList(actings, true)                // 先解当前接触（维持贴靠）
  qSP ← 所有 vState > SLOWER 的球                // 球-桌 CCD 队列
  qSS ← 同上（+低速球仅入 SS 队列）
  elapsed = 0
  while elapsed < T or qSP 非空:                 // 子步进主循环
      remaining = T - elapsed;  cap = strict ? remaining : ∞
      assert 迭代数 <= 100 else throw "Loop overflow"
      for ball in qSP: ccd.updateSPToi(ball, meshBody, spPool, …)   // 求球-桌撞击时刻
      if rechecks: flushRechecks(qSS, cap)                          // 复检旧接触
      for ball in qSS: ccd.updateSSToi(ball, balls, ssPool, …)      // 求球-球撞击时刻
      S = pendings.step2(remaining, p2a)         // 取最早撞击时刻；p2a=待处理接触
      if p2a 为空:                               // 本步再无碰撞
          for ball in balls:
              ball.step(S)                       // 直接推进
              if ball.y < lowestBoundY: inactivate(ball); outOfBoundsHandler(ball)  // 落袋/出界
          if 无球被唤醒: pendings.freeAll(); accumulator = 0    // 全员入睡→快进
          break
      if S > 0:
          elapsed += S
          for ball: ball.step(S)                 // 推进到撞击瞬间
          for c in p2a: 位移超阈值的接触标记岛重算 (islandUpdMinDisSq)
          islands.update(actings, false)
          for ball: predictionDirty && predVelocities(T - elapsed)
      for c in p2a:                              // 处理本时刻的撞击
          if 接触方失活: c.free()
          elif c.life == 0: actings.add(c); c.startResting(); touchPresolveHandler(c)  // ★新接触
          else: markRecheck(c)                   // 持续接触→稍后复检
      solver.solveList(actings, false)           // 冲量求解
      重新填充 qSP/qSS（按 vState）
```

关键语义：

- **碰撞发生在精确时刻**：球先推进到最早撞击点（`toi`），求解，再继续——不是普通引擎的"穿透后修正"，这是台球手感（分离角、吃库精度）的根基
- **`touchPresolveHandler(contact)`**：每次新接触建立时回调——★**击球声音的挂载点**（接触对象带 `label`/双方速度，可推音量音色）
- **落袋**：`position.y < meshBody.lowestPosition.y` → `inactivateBall` + `outOfBoundsHandler`
- **睡眠快进**：无球活动时清零 accumulator，跳过后续渲染帧的物理计算

### 4.3 接触管理

- `cActings`（模 94 类实例，容量 44）：持续接触集（含 `nIslands`、`markReupdate`）
- `cPendings`：待定接触；`spPool`/`ssPool`：模 38 对象池（各 70）
- 岛屿（模 34）：`initIslands`（reset 时）/`updateIslands`（每子步），`ccdSS/ccdSP` 复检

## 5. 击球模型（模 86 TipContact，L13645-13684，observed 全读）

击球被建模为一次**接触求解**：皮头是一个虚拟无限质量刚体（`invInertia=0`、`w=0`），与母球发生单次接触冲量。

```js
class TipContact extends Contact(模37) {
    label: "tip"
    restitution: 0      // 皮头不反弹
    friction: 0.9       // ★皮头高摩擦——塞(旋转)由此传入球
    bj(虚拟皮头): { v:(0,0,0), w:(0,0,0), radius: e[7], mass: 0.15, invMass: 1/0.15, invInertia: 0 }
    resetTip(ball, e):
        bj.radius = e[7]
        bj.v.set(e[3], e[4], e[5]).scale(e[6])            // 击球速度 = 方向 × 力度
        normal = normalize(ball.position - (e[0], e[1], e[2]))   // 接触法线 = 球心-触点
}
```

**输入契约 `e`（10 元数组，阶段 2 追溯其来源）**：

| 下标 | 含义 |
|---|---|
| e[0..2] | 皮头触点世界坐标（球面上的偏移点 → 决定高低杆/左右塞） |
| e[3..5] | 击球方向单位向量 |
| e[6] | 力度标量（速度缩放） |
| e[7] | 皮头半径 |

物理链条：偏心触点 → 法线偏离球心方向 → 接触冲量产生对球心的转矩 → `w`（角速度）获得旋转；`friction 0.9` 保证切向冲量足以"咬住"球面传递旋转。

`World.shoot(ball, e)`（L11863）：`tipContact = new TipContact(0.15)`（皮头质量 0.15）→ `resetTip(ball, e)` → `solver.solveContact(tipContact)` → `ball.wakeUp()`。
