# 电影比赛场景

状态：2026-11-13 用户批准扩展，实施中。默认仍为 116cebd 的 PCOL 着色与程序化球台组合；不是恢复旧 Frame 模型。本文维护电影外观，原作证据仍在 modules/render.md。

## 范围与入口

本地比赛用 `?visual=cinema` 启用，去掉参数恢复默认。外观在启动时选择，不在比赛中热换整个场景。联机装配不修改，缺省调用继续使用原外观。

保留确定性物理、规则、AI、声音、实时/回放快照和球杆动作。电影模式提供原瞄准、俯视、可环绕展示三个镜头；进入摆球、编辑、回放或正式暂停时交还既有输入和镜头。观察镜头不写控制器击球方向。

## 视觉依据

用户提供的 img/1.png—11.png 决定相对颜色、亮度、构图与简化风格。2026-11-13 用户说明这些图来自博主的本地模型，授权以克鲁斯堡及世锦赛赛台补足不可见结构。场景为单桌比赛厅，不宣称建筑测绘复刻。

- 星牌 [S101 官方结构资料](https://www.xingpaibilliards.com/Billiard-Table-details/S101.html)：台体、柱腿、四轨出球结构。资料中的产品外尺寸不覆盖项目物理尺寸。
- [WST 世锦赛场馆资料](https://www.wst.tv/worldchampionship/)：围合看台与比赛空间。保留本项目品牌，不复制赛事商标。
- 明亮绿色台呢、深红棕漆木、奶油色皮口、浅棉网、蓝围板白字、暗红分层座椅、灰墙。顶部条灯产生球体条状反射；暗部仍有层次。

## 实现边界

原木框/皮件/网兜/出球轨生成器增加只读样式入参，缺省值完全保留。球台尺寸和球径不是美术参数。装配根复制 applyTableGeometry 的静态 side 轮廓给 cinema，不访问 World/Body，也不重复实现袋角公式。tableJawShift 继续联动原台呢、皮口与网兜；精确库鼻由传入的物理边界生成。

电影材质与默认 PCOL shader 隔离。电影输出使用统一 image processing；不对原作已经 tone map/Gamma 的球与台呢直接套完整后处理。默认探针怪癖、阴影显隐时序和四元数同步保持。

外观参数分别在 table-style.ts（共同几何）、cinema-style.ts（电影材质、环境、灯光、镜头及后处理）维护；不复制物理参数。场馆、材质、pipeline 资源归 Scene；观察相机、DOM 与输入监听归装配，退出时释放。
